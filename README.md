# Sunsoul

ตลาดซื้อขายออนไลน์สำหรับลาว ใครก็ขายได้ และ **Sunsoul ถือเงินของผู้ซื้อไว้จนกว่าผู้ซื้อจะได้รับของ**

- ภาษาที่ลูกค้าเห็น: ลาว
- ตอนนี้ใช้งานจริงเป็น Claude Artifact: https://claude.ai/artifact/KJc78wr8491hPjLs1yeTPJ
- โค้ดในเวอร์ชันแรกของ repository นี้ = **v57** บน Claude

## โครงไฟล์

```
public/index.html            ทั้งระบบอยู่ในไฟล์เดียว: หน้าลูกค้า, หน้าร้าน, หน้าทีม, ข้อความภาษาลาว
public/backend-core.js       ตัวแปลง: ให้หน้าเว็บใช้ Firebase ได้ โดยไม่ต้องแก้หน้าเว็บ
public/backend-firebase.js   โหลด Firebase แล้วเปิดตัวแปลง (ใช้เฉพาะตอนเปิดจาก *.web.app)
public/firebase-config.js    ที่อยู่โปรเจกต์ Firebase sunsoul-01 (ไม่ใช่รหัสลับ)
tests/*.test.js              ชุดทดสอบ 18 ชุด (เปิดหน้าเว็บในเบราว์เซอร์จำลอง แล้วกดตามขั้นตอนจริง)
tests/fake-firebase.js       Firebase จำลองในหน่วยความจำ สำหรับทดสอบโดยไม่ต้องต่ออินเทอร์เน็ต
tests/fixtures/              รูปที่ชุดทดสอบใช้
tests/run-all.js             รันทุกชุดทดสอบ
```

## หน้าเว็บเดียว ใช้ได้ 2 ที่

- **เปิดบน Claude:** ใช้ฐานข้อมูลของ Claude Artifact เหมือนเดิม
- **เปิดจาก sunsoul-01.web.app:** โหลด `backend-firebase.js` ซึ่งให้ฟังก์ชันชุดเดียวกัน (db / assets / user) บน Firebase
  - ผู้เยี่ยมชมทุกคนได้บัญชีแบบไม่ระบุตัว (anonymous) ทันที ต่อไปล็อกอินด้วยเบอร์โทรจะผูกกับบัญชีเดิม
  - ทีมงาน = บัญชีที่มีชื่ออยู่ใน `admins/{uid}`
  - รูปอยู่ใน Firebase Storage ที่ `assets/<id>`

## แก้ข้อความภาษาลาว

ข้อความที่ลูกค้าเห็นอยู่ในตัวแปร `T` ใน `public/index.html`:

- ส่วนหลักอยู่ช่วงต้นไฟล์ ใน `const T={ ... }`
- ข้อความที่เพิ่มทีหลังอยู่ใน `Object.assign(T,{ ... })` (มีหลายก้อน)

ค้นหาข้อความลาวที่อยากแก้ (Ctrl+F) แล้วแก้เฉพาะในเครื่องหมาย `"..."` เท่านั้น
ระวังอย่าลบ `"` `,` หรือ `}` เพราะหน้าเว็บจะขาวทั้งหน้า

## รันชุดทดสอบ

ต้องมี Node.js 18 ขึ้นไป

```
npm install
npx playwright install chromium
npm test              # ทุกชุด
npm test -- sell      # เฉพาะชุดที่ชื่อมี "sell"
```

รูปหน้าจอจากการทดสอบจะอยู่ใน `tests/out/` (ไม่ถูกเก็บเข้า git)

## ระบบหลักโดยสรุป

| ส่วน | ทำอะไร |
|---|---|
| สั่งซื้อ → ร้านยืนยันมีของ → จ่าย QR → ทีมตรวจสลิป | เงินเข้า Sunsoul ไม่ใช่เข้าร้าน |
| LAO QR | สร้าง QR ที่มียอดของแต่ละออเดอร์จาก QR บัญชีรับเงิน (มาตรฐาน EMVCo / LAPNet) |
| สลิปไม่ผ่าน | ทีมเลือกเหตุผล บันทึกยอดที่ได้รับจริง ลูกค้าจ่ายเพิ่มเฉพาะส่วนที่ขาด |
| รับ-ส่ง | ทีมถ่ายรูปตอนรับของจากร้าน / ร้านต่างแขวงฝากขนส่งเอง |
| คืนสินค้า | ต้องมีวิดีโอแกะกล่อง · ใครเห็นของตอนแพ็กคนนั้นรับผิดชอบ · ร้านฝากเอง = ร้านรับผิดชอบ |
| โอนเงินให้ร้าน | หลังพ้นกำหนดคืนสินค้า · ออเดอร์ที่ร้านผิดจะไม่โอน |
| สมัครขาย | ชื่อ เบอร์ ที่อยู่ บัญชี + สินค้าชิ้นแรก → ทีมโทรยืนยัน → ร้านและสินค้าขึ้นเว็บทันที |

## ข้อมูล (ตอนอยู่บน Claude)

หน้าเว็บใช้ `window.claude.use("db" | "assets" | "user")` ของ Claude Artifact
ข้อมูลอยู่ในฐานข้อมูลของ artifact ไม่ได้อยู่ใน repository นี้

| กลุ่มข้อมูล | อ่าน | เขียน |
|---|---|---|
| products, shops, settings | ทุกคน | ทีม |
| orders, cases, shopProducts, upimgs | ผู้ใช้ที่ล็อกอิน | ผู้ใช้ที่ล็อกอิน |
| orderLock (ยอดเงินที่ล็อกแล้ว), sellerDecision, imgm | ผู้ใช้ที่ล็อกอิน / ทุกคน | ทีม |
| shopPrivate (บัญชีร้าน) | ทีม | ทีม |
| sellerApps/{ตัวเอง}, kyc/{ตัวเอง} | เจ้าของ + ทีม | เจ้าของ (ทีมอ่านได้ทั้งหมด) |

## แผนต่อไป: ย้ายไป Firebase

1. แยกส่วนต่อฐานข้อมูลออกเป็นไฟล์เล็ก (ฝั่ง Claude / ฝั่ง Firebase) ให้หน้าเว็บใช้ร่วมกัน
2. ล็อกอินด้วยเบอร์โทร + OTP
3. กฎความปลอดภัยรายคน: ลูกค้าเห็นแค่ของตัวเอง ร้านเห็นแค่ของร้าน
4. งานเบื้องหลัง (ยกเลิกเมื่อหมดเวลา, ล็อกยอดเงิน) ย้ายไปทำที่เซิร์ฟเวอร์
5. โหลดข้อมูลเฉพาะที่ต้องใช้ (ประหยัดโควตา)
6. อัปโหลดวิดีโอแกะกล่องในระบบ
7. แจ้งเตือนร้านและลูกค้า
